## Correction

Review version `generated-consistency-v4-source-references` replaces model-retyped quotation values with server-generated source IDs. The server creates a deterministic catalog of exact full fields and sentence spans. Spans longer than the existing 600-character quote limit are excluded, never silently clipped or paraphrased. Each quote slot receives an enum restricted to its existing allowed source fields; the model cannot select the canonical answer as independent actor/time/action evidence. Empty IDs remain permitted only where the previous quote contract allowed an empty quote.

After structured schema validation, the server resolves each ID to canonical text. The existing semantic verdicts, evidence obligations, ordinary-alternative check and literal quote validation still apply to the resolved review. Unknown IDs and IDs from the wrong source field fail closed. Selecting a real but irrelevant source remains a possible model error: this removes a transcription-failure class, not semantic uncertainty.

The model still receives the varied generated candidate. This does not substitute an authored case or remove review criteria. The prompt requests concise reasons citing IDs instead of repeating long passages. Output size and startup latency improvements are not established until the full path is run.

## Diagnostics and verification

It retains at most four failed quote slots and four allowed sources per slot; oversized invalid values are explicitly marked as truncated. It is written atomically under the ignored local data directory with private-file permissions. It contains no session/request capabilities and is never returned through HTTP or merged into playable data. Diagnostic write failure does not admit a case. This cannot retroactively recover the lost v3 response.
