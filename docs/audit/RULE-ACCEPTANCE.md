## Disclosure observations

The fixed synthetic output dataset has three legitimate examples and five examples labeled for withholding. The literal guard preserved all three legitimate examples (0/3 false positives), withheld three direct/internal examples, and allowed both semantic variants (2/5 false negatives). These denominators describe only the deliberately selected fixtures, not a sampled production rate. Preserving an adversarial input is intentional: player wording is not silently rewritten; the actor and authoritative outcome rules must handle it as untrusted dialogue.

The current rule is intentionally literal and documented that way. Strengthening semantic disclosure requires an explicit design decision about earned contradictions versus premature admissions, then a targeted evaluation; adding keyword overlap back would restore the previously demonstrated false positives. This report does not perform that model-policy redesign.
